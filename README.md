# PCEP Python Practice

Repositório público para treinar habilidades e conhecimentos em Python em preparação para o exame **PCEP™ – Certified Entry-Level Python Programmer**.

## Objetivo
- Praticar fundamentos de Python cobrados no exame PCEP.
- Organizar exercícios por tema e nível de dificuldade.
- Usar o **PyCharm Pro** como ambiente principal de desenvolvimento.

## Estrutura inicial
- `exercicios/`: scripts de prática por assunto.

## Roteiro de estudo sugerido (PCEP)
1. Tipos de dados, variáveis e operadores.
2. Controle de fluxo (`if`, `for`, `while`).
3. Funções e escopo.
4. Coleções (`list`, `tuple`, `dict`, `set`).
5. Exceções e entrada/saída básica.
6. Módulos e pacotes.

## Como usar no PyCharm Pro
1. Abra este repositório no PyCharm Pro.
2. Crie um interpretador virtual (venv) no projeto.
3. Execute os arquivos em `exercicios/` para praticar.
4. Evolua os exemplos e adicione novos exercícios por tópico.
